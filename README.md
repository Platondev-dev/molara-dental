# Molara — сайт стоматологии

Демонстрационный сайт вымышленной клиники в Кишинёве. Главная идея: пациент узнаёт примерную цену до визита и сразу записывается онлайн.

## Возможности

- Три языка (RO, RU, EN), выбор сохраняется между визитами
- Калькулятор стоимости с переключением MDL и EUR
- Перенос выбранных услуг из калькулятора в форму записи
- Запись на приём: выбор даты и времени, воскресенье закрыто, занятое время недоступно
- Проверка формы и формата молдавского номера телефона
- Адаптивная вёрстка и работа с клавиатуры

## Технологии

HTML, CSS (Grid, Flexbox, переменные), JavaScript без библиотек, localStorage.

## Запуск

Откройте `index.html` в браузере. Сборка не нужна.

## Ограничения

Сервера нет: записи хранятся только в браузере посетителя, а часть занятых часов имитируется в коде. Клиника, цены и контакты вымышлены.
